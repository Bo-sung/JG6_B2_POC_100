# 100 LIVES VS 1 BOSS — POC 문서 패키지

- 문서 버전: 0.1 / 2026-11-07
- 목적: 게임 잼 주제 **Inconvenient Superpowers**를 검증할 플레이 가능한 Unity 사이드뷰 보스전 POC 제작
- 작업 전제: **기존 Unity 7 프로젝트/템플릿 기반**. 실제 에디터 버전과 패키지는 작업 시작 시 `ProjectSettings/ProjectVersion.txt`, `Packages/manifest.json`을 확인한다. 임의 업그레이드/다운그레이드 금지.
- 기준: **이 패키지는 기획 합의 사항의 기준 문서**이며, 구현 도중 발생하는 판단은 `GAME_DESIGN.md`의 불변 원칙을 우선한다.

## 문서 읽는 순서

1. `GAME_DESIGN.md` — 게임의 핵심, 100목숨 루프, 입력, 20종 능력, 보스 패턴, UI, POC 범위
2. `MDA_ANALYSIS.md` — 목표 감각, 메카닉→다이내믹→경험, 실패 위험, 플레이 테스트
3. `TECH_SPEC.md` — 능력 아키텍처, 피해·사망·부활, 효과 시스템, 구조·테스트·완료 기준
4. `IMPLEMENTATION_PROMPT.md` — 개발 에이전트에게 그대로 전달할 실행 프롬프트

## 초단기 인수인계: 절대 잃으면 안 되는 사실

- **2D 사이드뷰 플랫폼 액션**, 의도적으로 저예산·허술해 보이는 B급 유머. 단, **조작감과 타격 판정은 정확**해야 한다.
- 기본 동작 **WASD, 점프, 대시, 평타**. 한 목숨에 **초능력 1개만** 사용.
- 초능력이 기존 기본 동작에 섞이면 **패시브**이므로 **스킬 버튼 없음**. 별도 발동 능력일 때만 스킬 버튼 표시·사용.
- 108 무구/아우터즈의 핵심 착상은 **압도적으로 강하지만 사용자에게 안전하지 않은 힘**. 일반적인 쿨다운/마나 페널티 게임으로 변질 금지.
- **20종 능력 × 각 5회 = 100개 목숨**. 20종 1개씩 포함된 세트 5개를 각각 섞어서 순차 지급. 같은 런에서 정확히 다섯 번씩 배정(클리어 전 미사용 가능).
- 플레이어는 1 HP; 죽을 때마다 새 능력으로 빠르게 부활. **보스 HP·페이즈는 유지**, 플레이어 상태·이전 목숨의 효과는 정리.
- 우상단에 **PUBG식 간결하고 하찮은 사망 킬로그** 최대 5줄. 잘못된 원인으로 죽인 척 표시하지 않는다.
- 보스는 정통 사이드뷰 보스 클리셰: 대검 횡베기/내려찍기/돌진/지면 충격파/마력탄/운석/레이저. 체력이 많고 약점 퍼즐은 없다.
- POC 최종 범위는 **능력 20종 전체 + 보스 1종 7패턴 + 100목숨/킬로그/완주 루프**. 제작은 대표 능력 5개로 공통 시스템을 먼저 검증한 후 전부 확장한다.
- 주제는 **불편함을 능숙하게 역이용하는 재미**로 표현한다. 능력 없이 평타만 쓰는 편이 항상 좋거나, 즉시 자살하여 능력만 바꾸는 편이 항상 좋다면 실패.

## 콘텐츠 출처와 권리

A.Shipwright의 **아우터즈/108 무구**에서 영감을 받은 내부 기획안이다. 문서의 능력 명칭·설명에는 이전 기획 대화의 가칭, 편의상 각색한 기능, 신규 창작 능력이 혼합되어 있다. **원작 설정과의 1:1 일치 여부는 검증되지 않았다.** 공개 배포 시 원작 고유 명칭·외형·서사를 그대로 사용하지 말고 권리 확인 또는 독자적 변형이 필요하다. 이름과 아트는 초기 POC에서 교체 가능한 데이터로 취급한다.
