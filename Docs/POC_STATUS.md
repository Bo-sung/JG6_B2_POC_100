# POC 현재 상태

- Unity 6000.6.8f1 / URP 17.6.0 유지, 작업 브랜치 `feature/mouse-aim`. `ba7b72a` 위의 기존 마우스 조준 변경을 확장했다. 커밋·푸시·master 변경 없음.
- 기본 체력 1, A12만 체력 6. 생명마다 능력 런타임 하나, 20종×5세트=100목숨, 보스 HP/페이즈 영속과 보스 우선 동시 승리 유지.
- Q 유지 전방 가드: 조준 방향 ±65도. B01 경량 물리만 기본 방어, B02~B04 중량 공격은 불가. B05~B07 마법은 A11의 Q로만 방어한다. 소유자 효과·낙사·벽 충돌은 가드 대상이 아니다. 패리 없음.
- 입력은 자산 복제/FindAction, Update 수집/FixedUpdate 처리. A/D·Space·공중 S·마우스 조준·Shift·J/LMB·K/RMB 유지. `active`는 K 제공 여부이며 기본 행동/가드 훅과 병용한다.
- Player.prefab과 ArenaPOC에 방패·검·충전 표시·체력/취약 상태 HUD를 저작했으며 빌더도 같은 구조다. 효과는 기존 160개 씬 슬롯을 재사용한다.

- JSON→DTO→TableManager→GameTableRules 유지. 가드 각도·피해 종류·체력·충전·궤적·이동/추락 임계·침강 수치는 테이블 원본이다.
- 사망·재시작·디버그 장착에서 효과·가드·취약성·체력 수정·충전 고정·중량화·거대화·유체 상태를 정리한다. 비치명 피해는 생명 감소/Death를 발행하지 않는다.
- `player_health`는 실제 피해와 A12 취약성 활성 때만 GameEvents→TelemetryRecorder 경로로 기록한다. 가드 자세/조준/프레임별 분석 로그는 남기지 않는다.
- 이전 자동 통합 시나리오는 1HP·K 가드·공중 S A19를 전제하므로 진입을 명시적으로 차단하고 메뉴에서 제거했다. Debug Arena의 Lose one life는 체력과 무관하게 확정 사망이다.
- 이번 수정은 컴파일·Edit-mode 저작/참조 확인만 수행한다. Play·테스트·입력 주입·스크린샷·진단 플레이 실험 없음. `ba7b72a`의 기존 성공/사용자 확인과 마우스 조준 컴파일 결과는 이번 능력 개정의 플레이 증거가 아니다.
- 미완료 검증: 새 가드/능력 전부의 사용자 플레이, 조작감·밸런스·장시간 정리·전체 회피 가능성·독립 실행 빌드. A18 향후 재설계와 마법 패리는 보류. 오디오·세이브·외부 분석 전송은 기존 미구현 상태다.
