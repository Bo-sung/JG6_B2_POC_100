# POC 현재 상태

- Unity 6000.6.8f1 / URP 17.6.0 유지. Assets/Scenes/ArenaPOC.unity에서 바로 Play 가능하며, 빌드 진입은 Preload → Title → ArenaPOC다. 기존 Game 씬도 빌드 목록에 보존했다.
- 단일 플레이어, 1HP, 한 목숨에 능력 하나, 20종을 한 번씩 섞은 5세트=100목숨. 사망 후 0.65초 부활·1초 안전 시간. 보스 HP·페이즈는 사망 후 유지하며 같은 프레임의 동시 사망은 보스 처치 승리 우선이다.
- ArenaSession과 씬 서비스 호스트가 실행 상태를 소유한다. 미리 배치한 효과 160슬롯을 비활성화·재사용하며 사망 때 전생의 효과·예약·모터 상태를 정리한다.
- HUD·킬로그 5슬롯·승패 패널은 PanelBase/View/Presenter 구조다. 재시작은 버튼/Enter. 위치·프리팹·뷰는 Editor에서 저작하고 런타임에는 생성하지 않는다. 한국어 폰트는 Noto Sans KR이며 라이선스는 Art/OFL.txt에 포함했다.
- 입력: A/D, W/S 방향, Space 점프, Shift 대시, J/좌클릭 평타, K/우클릭 액티브. 새 Input System만 사용하고 원본 액션 자산을 복제한다. 물리는 FixedUpdate에서 처리한다.
- 수치·문구 원본: ArenaTableData.json → GameTables.cs/GameTableRecords.cs → TableManager.Arena → GameTableRules. AbilityDefinition 20개에는 ID만 저장한다. TECH_SPEC의 SO 수치 저장안은 AGENTS 규칙에 맞춰 JSON으로 바꿨다.
- 제작/개발 도구: Tools/POC/Build Arena Scene, Debug Arena, Run Integration Checks (Play Mode). 디버그 코드는 Editor/DEBUG 관리 코드 변형에 한정한다.

- A01~A20 모두 고유 런타임이 존재하고 발동 훅을 실행했다. 공격형 18종은 각각 보스 피해를 확인했고 A11/A20은 방어·통과 동작을 확인했다. 표의 일부 결함은 코드 구현 범위를 함께 설명하며, 모든 거리·타이밍 조합을 검사했다는 뜻은 아니다.
- 보스 B01 횡베기, B02 내려찍기, B03 돌진, B04 지면 충격파, B05 마력탄 3연사, B06 운석, B07 상향 레이저 구현. B01~B05는 1페이즈, HP 50% 이하에서 B06~B07 추가. 세 연계 B01→B02/B02→B04/B05→B03은 2페이즈에서만 사용하며 기존 회복 시간·휴지기를 유지한다.
- 7패턴을 능력 없이 기본 동작으로 한 번씩 회피했고 세 연계 전환을 확인했다. 전체 전투에서의 모든 위치·연계 회피 가능성은 사람 플레이로 추가 평가해야 한다.
- 분석은 GameEvents → TelemetryRecorder → TelemetryLog 경로다. life_end에 목숨·능력·생존·피해·사인·보스 패턴·덱 시드를 집계하며 시계는 GameTime 하나다. 결과는 arena_result summary로 기록한다.
- 컴파일 오류/경고 0, ProjectValidation 통과, 100회 사망·승리 우선·전생 상태 정리·입력·진입 흐름·JSONL 계약 확인. 자세한 범위와 산출물은 POC_TEST_REPORT.md.
- 남은 작업: 사람의 5~8분 완주·두 명 이상 블라인드 평가·조작감/능력별 효율 튜닝. 오디오·세이브·외부 분석 서버 전송·독립 실행 빌드는 이번에 구현/검증하지 않았다.
