# MDA ANALYSIS — 100 LIVES VS 1 BOSS

> 대상은 구현 전 **기획 가설**이다. 점수는 관찰 결과가 아니라 목표 우선순위를 표현한다. 플레이 테스트로 검증해야 한다.

## 1. 핵심 가설

**Inconvenient Superpowers를 '큰 능력 + 작은 수치 페널티'가 아니라, 강점의 사용 방식 자체가 플레이어에게 위험을 만들어내는 시스템으로 표현하면 재미있는 전투 의사결정이 발생한다.** 100개 목숨과 지속되는 보스 HP는 그 위험한 실험을 부담 없이 반복하게 만든다.

목표 미학 우선순위: **Sensation → Challenge → Discovery**, 보조: **Fantasy / Expression**. Narrative, Fellowship, Submission은 핵심이 아니다.

## 2. Mechanics — 실제 구현 가능한 규칙

| 층 | 메카닉 | 생성하려는 선택 |
|---|---|---|
| 코어 입력 | WASD, 점프, 대시, 평타, 선택적 스킬 1개 | 공격·회피·거리 조절 |
| 초능력 계약 | 매 생명마다 능력 하나, 패시브는 기존 행동 변경 | 현재 주어진 도구로 전투 방식 변경 |
| 이중 효과 | 강한 효과 + 사용자에게도 적용되는 결함 | 타이밍·위치·방향·충돌 관리 |
| 자해 공통 판정 | 본인도 광선/참격/넉백/낙뢰 피해 가능 | 부작용 예상 및 우회 |
| 100목숨 덱 | 20종 × 5세트 셔플, 죽으면 교체 | 실패를 수용하고 다음 능력에 적응 |
| 보스 | 높은 HP, 전형적 7패턴, 예고·후딜 | 반복 관찰, 적절한 위험 사용 시점 찾기 |
| 진행 영속 | 보스 HP/페이즈 유지, 플레이어 상태 초기화 | 매 생명의 누적 기여를 느끼기 |
| 피드백 | 우상단 간결한 사망 킬로그 | 사인 이해, 웃음, 개선된 재시도 |
| 즉시 재시도 | 빠른 부활, 전생 효과 제거 | 실험의 리듬 유지 |

### 결함 설계의 판별식

좋은 결함: `높은 위력 → 환경/자신과 실제 상호작용 → 위험 생성 → 플레이어의 선택으로 위험 경감 또는 공격 활용`.

나쁜 결함: `높은 위력 → 마나 -20 / 쿨다운 5초 / 무작위 30% 즉사`. 후자는 이 게임에서 주제를 체험하게 만드는 핵심 행동이 약하다.

## 3. Dynamics — 전투 중 예상되는 실제 행동

### 의도한 다이내믹

1. **견적 내기:** 보스 돌진 예고를 보고 참격을 미리 깐다. 뒤로 빼다가 자기 칼날에 닿지 않도록 높이를 바꾼다.
2. **자기 반동 이용:** 초근력으로 보스를 때리고 반대편으로 밀려나는 힘을 회피/이동으로 바꾼다.
3. **목숨을 자원으로 교환:** 인간 폭탄은 안전하게 오래 버티는 능력이 아니라 목숨 1개를 보스 HP와 바꾸는 수단이 된다.
4. **죽음에서 학습:** 첫 티알파 대시는 벽에 박아 죽지만, 같은 능력을 다시 받으면 거리를 계산한다.
5. **관찰→기회 포착:** 보스의 후딜을 이용해 충전형 능력이나 지연 공격을 성공시키려 한다.
6. **하찮은 승전보:** 보스 HP를 조금씩 깎고 '본인의 다리', '벽', '낙뢰' 같은 사인이 쌓여 코미디가 축적된다.

### 원치 않는 다이내믹과 방지책

| 문제 | 관찰할 징후 | 우선 대책 |
|---|---|---|
| 능력 무시 | 평타/대시만 사용하는 것이 항상 이득 | 능력 적중 기회를 늘리고 강점을 뚜렷하게, 단 결함은 유지 |
| 자살 리롤 | 받은 능력 확인 후 보스에 접근하지 않고 자살 | 능력 간 성능 보정, 자살 시간·효율 지표 관찰 |
| 정답 조합 강제 | 특정 보스 패턴에 특정 무구가 없으면 불가능 | 모든 보스 패턴의 기본 조작 대응 검증 |
| 불가피한 연쇄사 | 능력의 자동 발동으로 스폰 직후 사망 | 부활 무적/효과 소유권/안전 위치/입력 버퍼 검증 |
| HP 노동 | 보스가 쓰러질 때까지 같은 행동 반복 | 높은 한 방과 명확한 후딜, 적정 HP 재조정 |
| 능력 없는 시간 | 충전/대기 동안 회피만 강요 | 예비 입력·유효 공격 기회·발동 조건 재설계 |
| 너무 얌전한 연출 | 초능력 사용이 일반 스킬과 차별 안 됨 | 과장된 효과·자기 위험·킬로그 강화 |

## 4. Aesthetics — 8가지 경험 목표

| 미학 | 목표(기획 우선도 1~5) | 의도한 경험 | 핵심 구현 | POC 검증 신호 |
|---|---:|---|---|---|
| **Sensation** | **5** | 강력한 타격, 어이없는 자해·넉백 | 큰 충격·히트스톱·짧은 사망 연출 | 능력 사용 시 타격/위험을 즉시 알아챔 |
| **Challenge** | **5** | 자신이 감당 못 할 힘을 안전하게 맞히는 숙련 | 보스 예고, 위험한 스킬, 회피·착지 | 동일 능력 재등장 때 성과가 개선됨 |
| **Discovery** | **4** | 결함의 역이용 발견 | 자기 피해 판정·환경 상호작용 | 사용자가 설명 밖의 유효 전략을 발견 |
| **Fantasy** | **4** | 허접한 용사가 전설적 힘으로 마왕에게 덤빔 | 압도적 위력과 우스운 실패의 대비 | 플레이어가 '약하지만 강하다'고 설명 |
| **Expression** | **3** | 같은 능력으로 서로 다른 싸움법 | 위치·타이밍·패턴 유도 | 같은 능력에서 복수의 처치 방법 등장 |
| **Submission** | **2** | 실패해도 계속 달려드는 반복 도전 | 빠른 재등장, 누적 보스 HP | 긴 화면 전환 없이 플레이를 계속함 |
| **Narrative** | **1** | 100명 희생자의 허무한 전설 | 킬로그·이름·엔딩 문구 | UI만으로 유머 맥락이 전달됨 |
| **Fellowship** | **1** | 단독 플레이, 관전 시 웃음 | 사망 킬로그 | 필수 POC 지표 아님 |

**해석:** '짜치는' 것은 Sensation의 수준을 낮추는 것이 아니라, **연출 소재와 미술 표현의 허술함을 이용한 코미디**를 뜻한다. 피격/사운드/입력 피드백의 전달력은 높아야 한다.

## 5. MDA 인과관계 사례

| Mechanics | 플레이 중 Dynamics | 결과 Aesthetics |
|---|---|---|
| 초고속 대시 + 감속 불가 | 벽을 피할 각도와 거리 계산, 보스 돌진과 교차 | Challenge + Sensation |
| 공간에 남는 참격 + 자기 접촉 판정 | 함정 설치 뒤 안전한 공간 확보, 보스 유인 | Discovery + Expression |
| 평타 자기 넉백 | 반동을 회피·높이 확보에 활용 | Sensation + Discovery |
| 1HP + 100목숨 + 빠른 리스폰 | 실패 비용 낮아 과감한 실험 증가 | Submission + Challenge |
| 높은 보스 HP·후딜 | 강력한 일격 타이밍을 반복 학습 | Challenge + Fantasy |
| 킬로그 | 황당한 사망이 웃음과 단서로 바뀜 | Narrative(소량) + Sensation |

## 6. POC 검증 질문(가설→측정)

### H1. 불편함이 '쓰고 싶은 능력'으로 작동하는가?

- 지표: 능력별 등장 횟수, 기본 동작 변경 사용 횟수/액티브 사용 횟수, 능력별 보스 피해, 능력별 본인 사망 원인.
- 관찰: 플레이어가 능력을 의도적으로 활용하는가? 설명을 이해해도 계속 능력을 포기하는가?
- 실패 시: 능력 강점과 실전 사용 기회를 개선하되 불편함은 지우지 않는다.

### H2. 100목숨이 좌절 완화와 숙련을 동시에 만드는가?

- 지표: 사망→다음 입력까지 시간, 목숨당 생존 시간·입힌 피해, 동일 능력 1~5회차의 성과 변화.
- 관찰: 사망 직후 웃거나 재시도를 시도하는가, 지루하게 기다리는가?
- 실패 시: 부활 속도·킬로그 전달력·보스 HP 조정.

### H3. 보스는 초능력의 실험대가 되는가?

- 지표: 패턴별 사망 비중, 패턴별 능력 적중 수, 보스 패턴의 불가피 피격 건수, 보스 HP 감소 곡선.
- 관찰: 보스가 능력을 활용할 기회를 주는가, 너무 공격적이어서 플레이가 회피만 되는가?
- 실패 시: 예고·후딜·패턴 선택 가중치 조절.

### H4. 이 게임만의 B급 개그가 전달되는가?

- 지표: 플레이 테스터가 기억한 사고 2개, 기억한 킬로그 문구, 웃었던 순간의 타임스탬프.
- 관찰: '버그로 죽었다'보다 '내 능력에 내가 죽었다'고 이해하는가?
- 실패 시: 실루엣/위험 예고/킬로그 원인 정확도 개선.

## 7. 최소 플레이 테스트 시나리오

1. **기본기 테스트:** 초능력 없이 보스의 7패턴 전부 회피 가능해야 한다.
2. **대표 능력 테스트:** A01(참격), A02(대시), A05(반격), A13(초근력), A16(자폭)을 고정 지급하여 단위 테스트.
3. **20종 순환 테스트:** 20개 한 세트로 능력 전부 체험, 패시브 스킬키 비활성 확인.
4. **100목숨 고갈 테스트:** 마지막 생명 사망 후 패배; 카운트 누락/중복 없음.
5. **동시 사망 테스트:** A16 자폭과 보스 사망 동시 발생 시 승리.
6. **상태 초기화 테스트:** 거대화/유체화/초속 이동 상태로 죽은 뒤 새 능력에 충돌·중력 상태가 남지 않음.
7. **자살 리롤 테스트:** 의도적으로 버리려는 능력 목록과 이유를 기록.
8. **두 명 이상 블라인드 테스트:** 규칙 설명을 최소로 하고 초기 반응/사망 원인 이해도 관찰.

## 8. 최초 합격 게이트(실험용 기준)

- 보스 패턴 7종 중 불가피한 피격 패턴 **0개**(기본 조작 기준).
- 킬로그의 원인/희생자 정확도 **100%**(자동 테스트 대상 사망 경로).
- 일반적인 사망 후 재조작 가능까지 **1초 이내**(임시 목표).
- 100장 능력 덱에서 20종이 정확히 5장씩이며 중복/누락 **0건**.
- 20종 중 **모든 능력**이 최소 1개의 고유한 전투 행동과 명확한 결함을 갖는다.
- 여러 플레이 테스터가 능력의 단점을 **예측하고 회피하는 행동**을 실제로 보인다.
- 보스 HP는 사망 후 보존, 시작부터 100목숨 고갈까지 오류 없이 루프가 완주됨.

> 점수·수치는 **검증 목표**이지 이미 달성한 결과가 아니다. MDA 가설이 틀리면 콘텐츠 수를 유지한 채 피해·패턴·입력 타이밍을 먼저 조정한다.
